# adaption-neuromuscular-assistance
This is a closed loop assistive device which operates on the neuromuscular system, utilising EMG-based exhaustion/fatigue detectors alongside adaptive electronic stimulation, embedded sensory systems and biomechanics.


# Overview
The intention of this project was to explore if using real-time neuromuscular fatigue detectors can be beneficial in providing assistance in strength and conditioning via electrical stimulation.
