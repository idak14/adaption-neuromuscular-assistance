# adaption-neuromuscular-assistance
This is a closed-loop  device of assistance  which successfully operated on the neuromuscular system of 50 individuals out of 60, utilising EMG-based exhaustion/fatigue detectors alongside adaptive electronic stimulation, embedded sensory systems and biomechanics.

* This project aimed  specifically to  target individual performance in completing bicep curls.

# Overview
The intention of this project was to explore if using real-time neuromuscular fatigue detectors can be beneficial in providing assistance in strength and conditioning via electrical stimulation.  

The system I created aimed to combine mechanical sensing with physiological capabilities in order to identify phases of movement to identify and  supersede exhaustion in a safe manner. By using pressure sensors, I  preidentified signs of fatigue, which triggered electricity to adaptively assist muscular contraction,aiding a natural and controlled eccentric phase.

# Area's Integrated
EMG- required to monitor signs of fatigue within neuromuscular activity
Pressure sensing- detects contrasts (peak contraction and relaxation) 
Accelerometery- counts 'reps' and unilateral movement*  
Electrical stimulation- Acted as a 'boost', providing stimulation for controlled assistance in relation and contraction
Embedded systems with AI + Signal Processing- initiated a 'kick-start' feature for electrical stimulation by identifying early onset signs of fatigue (time taken between each full repetition)
Biomechanics- Assisted the embedded systems and signal processing by actively analysing mobility throughout each repetition.
